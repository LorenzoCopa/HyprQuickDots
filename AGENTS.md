# AGENTS.md

Personal Hyprland (Wayland) dotfiles. Not a git repo — no `git` operations. Comments and UI strings are written in Spanish; keep new content consistent.

## Symlinking to ~/.config (live config)

Everything in this repo is symlinked into `~/.config` on this machine, so edits here are **live immediately**. Do not "deploy" anything; changes to a file are active on the next reload/restart.

Requires `sudo`; copy manually after editing (e.g. `sudo cp -r sddm/evergarden/. /usr/share/sddm/themes/evergarden/`). The theme mirrors the Quickshell lock design (seven-segment clock + blurred wallpaper). **The background is a STATIC pre-blurred image** (`wallpaper-blur.jpg`, generated with ImageMagick, referenced in `theme.conf` as `background=`) — SDDM runs as the `sddm` user (uid 960) which can't read `~/.cache/awww/` or `~/Wallpapers/` (home is `drwx------`), and there's no live screen to capture at login. To update it when the wallpaper changes: `magick ~/Wallpapers/<wallpaper> -blur 0x24 -brightness-contrast -10x-10 -quality 82 sddm/evergarden/wallpaper-blur.jpg` then re-copy with `setup.sh --sddm`. `SevenSegmentDigit.qml` in the theme is a port of `quickshell/launcher/SevenSegmentDigit.qml` (pure QtQuick, `segColor` instead of `Settings.accent`). |

When adding a new top-level config dir, create the symlink `ln -s ~/Repos/HyprQuickDots/<dir> ~/.config/<dir>`.

**`setup.sh` recreates all the symlinks above automatically** (idempotent; backs up real files to `.bak`). Run `./setup.sh` after cloning/reinstall, `./setup.sh --sddm` to also copy the SDDM theme (needs sudo), `./setup.sh --dry-run` to preview. From scratch, prefer `./install.sh` (below) which calls `setup.sh` plus installs every dependency.

## Instalador `./install.sh` (nuevo, Arch/CachyOS)

- `install.sh` es el instalador interactivo "hazlo todo": detecta distro (pacman), instala paquetes del sistema (todo desde repos oficiales, sin AUR), quickshell, fuentes, fontconfig (Dota 2), whisper/dictado (modelo interactivo), servicios systemd, symlinks (`setup.sh`) y SDDM.
- Lógica compartida en `install/lib.sh` (source, no ejecutable): `info/ok/warn/error/section/step_banner`, `detect_distro`, `pac_install` (idempotente, respeta `--dry-run`), `check_cmd`, `confirm`/`confirm_run`, `link_file` (respaldando real a `.bak`), `run`.
- `systemd-user/` contiene `quickshell.service` y `awww.service` — el instalador los copia a `~/.config/systemd/user/` y los habilita (arrancan con `graphical-session.target`, vía uwsm).
- `fontconfig/fonts.conf` sustituye Arial/Tahoma/Verdana (p. ej. para Dota 2): el instalador lo enlaza a `~/.config/fontconfig/fonts.conf`.
- `sddm.conf` configura `[Theme] Current=evergarden` + autologin hydra; el instalador lo copia a `/etc/sddm.conf.d/10-hyprquickdots.conf`.
- Flags: `--no-whisper --no-sddm --no-gaming --no-interactive --dry-run --help`. Gaming (cachyos-gaming-meta+steam) y SDDM son opcionales y preguntan. El dictado pide elegir el **modelo** de whisper interactivamente (no descarga uno pesado sin consentimiento).
- **`--menu`** activa un seleccionador interactivo de secciones: lista las 16 secciones con estado `[x]`/`[ ]` (dictado/gaming/SDDM vienen desmarcadas), escribe el número para alternar, `t`=todo, `n`=nada, enter=instalar lo marcado. Las secciones se registran en `register_all_sections()` (id, nombre, desc, función, default) y se numeran dinámicamente según cuántas se elijan (`SECTION_ORDER` + `SECTION_STATE`). Los banners usan `step_begin()` con contador global `STEP_COUNT`/`STEP_TOTAL` (en `lib.sh`), en vez de `step_banner N 14` fijo.
- Fuentes locales: `fonts/` (Rubik.zip si existe) → `~/.local/share/fonts/` + `fc-cache -fv`. No hay `fonts/` ahora, solo se avisa.
- Verificación: `bash -n install.sh && bash -n install/lib.sh`; probar con `./install.sh --dry-run --no-interactive` (no cambia nada).
- `PACKAGES.md` (raíz) lista **todos** los paquetes por sección con su motivo de instalación (explícito/dependencia) y comandos manuales; es la referencia para saber qué instala el instalador y qué llega solo como dependencia (obviados: jq vía hyprshot, pipewire-audio vía pipewire-pulse/alsa, xdg-desktop-portal-gtk vía gtk4, vulkan-tools vía gaming). La sección Quickshell incluye `adw-gtk-theme` (temas GTK de `scripts/set-theme.sh`) y la sección Sistema incluye `power-profiles-daemon` (tile de energía del QuickAccess, arrastra `upower`).
- **`install-cli.sh` es el respaldo CLI** (independiente, no usa `lib.sh`): instala todo en bloque con un solo `pacman -S --needed` + quickshell, fuentes, fontconfig, servicios, symlinks y SDDM (todo de repos oficiales, sin AUR). Por defecto sí instala gaming/SDDM; flags `--no-whisper --no-gaming --no-sddm --dry-run --help`. Verificación: `bash -n install-cli.sh` y `./install-cli.sh --dry-run`.

## Architecture

- **Hyprland config is Lua** (`hypr/hyprland.lua`), using the `hl.*` DSL — NOT `hyprland.conf`. Split into `hypr/modules/*.lua` (shortcuts, gaming, quickshell helpers). `.luarc.json` is the Lua language-server config and declares the `hl` global. After editing: `hyprctl reload`. **`reload()` returns `require(name)`** (it used to return the module but a `local shortcuts = reload(...)` must receive it), so `local shortcuts = reload("modules.shortcuts")` must be the FIRST reload call; modules that register binds do `local shortcuts = require("modules.shortcuts")`.
  - **`hypr/modules/shortcuts.lua` is the single source of truth for keybinds**: every bind must use `shortcuts.bind(keys, action, opts, desc, cat)` (pass-through to `hl.bind`, `desc`/`cat` in Spanish, categories `General`/`Ventanas`/`Navegación`/`Escritorios`/`Sistema`/`Quickshell`/`Capturas`/`Zoom`/`Gestos`/`Otros`; gestures/mouse-chords via `shortcuts.entry`). `shortcuts.dump()` at the end of `hyprland.lua` writes `quickshell/shortcuts.json` (`{ "items": [ { keys, desc, cat } ] }` — object, NOT a bare array) on every `hyprctl reload`, so the Atajos section always shows the REAL live binds, never a copy. Binds are wrapped with `shortcuts.bind` in `hyprland.lua`, `quickaccess.lua`, `dictation.lua`, `voicecmd.lua` (gaming.lua is disabled/commented but kept consistent). New binds MUST go through `shortcuts.bind`, or they won't appear in the Atajos search.
- **Quickshell** (`quickshell/`): QtQuick/QML shell. Entrypoint is `quickshell/shell.qml` (bar, launcher, screenshot, clipboard, lock, idle, wallpaper, polkit, switcher). Shared singletons live in `quickshell/config/` (`Settings.qml`, `Icons.qml`, `SymbolicIcon.qml`; declared in `qmldir`).
  - Widgets are driven externally via `qs ipc call <target> <action>` (bound in `hyprland.lua`, e.g. `qs ipc call launcher toggle`). The IPC target names must match the `IpcHandler { target: ... }` in the QML.
  - FloatingWindow titles are coupled to window rules: e.g. launcher title `qs-launcher` must match the `match = { title = "qs-launcher" }` rule in `hypr/modules/quickshell/launcher.lua`. Renaming one without the other breaks it.
  - `launcher/Launcher.qml` is a pure search box (empty query shows no results). `launcher/AppBrowser.qml` is a separate window with a **search box + curated categories in chips (Todas/Internet/Oficina/Multimedia/Juegos/Sistema/Desarrollo/Otros) + grid view** (GridView; each app is assigned to a curated category by mapping its XDG `.desktop` categories via `curatedFor`). It has NO keybind — it is opened from the launcher via the `Aplicaciones` desktop entry (`applications/aplicaciones.desktop`, `qs ipc call appbrowser toggle`). **Va EN MOSAICO (sin regla flotante en Hyprland) y por eso su fondo es de esquinas rectas** (`radius: 0`), igual que la Configuración (`qs-settings`), que también va en mosaico sin regla de ventana — el fondo (Rectangle `bg`) de esas dos ventanas usa `radius: 0` para que las curvas no se vean raras al expandirse en el mosaico.
  - `quickaccess/QuickAccess.qml` is a quick-access menu (Android-style) opened with SUPER+B (`qs ipc call quickaccess toggle`, IPC target `quickaccess`). It is an overlay of separated tiles: a media player (`quickaccess/MediaHeroPanel.qml`, a dedicated hero "now-playing" card in a **2×3 grid** — LEFT column: **square album art** (`artWrap` 80px, `heroArt` loads at 480px, no blurred backdrop — card background stays solid so the art reads crisp) with the title (up to 2 lines, bold) + artist·album below it; RIGHT column top to bottom: a **bar-equalizer visualizer** (a `Canvas` painting directly on the card background — NO `Settings.surface` panel behind it, it blends with the black `cardBg` — animating ~18 rounded bars from the real measured audio peak (`PwNodePeakMonitor`), each bar with a fixed pseudo-random factor (`barFactor`, seeded sine-hash) so they don't all rise together, smoothed with a fast-attack/slow-release envelope per bar and alpha that brightens with the level — **OJO — `ctx.roundRect` NO existe en el Canvas de quickshell** (TypeError en runtime, el ecualizador quedaba vacío): las barras se trazan a mano con `arcTo` en la función `drawBar` del propio Canvas), the progress bar with times at the sides (or a LIVE marker for live streams), and the compact circular controls **previous/play/next plus a REPEAT button** (shown only if `loopSupported`; cycles `MprisLoopState` None→Track→Playlist via the `loopState` property, which is writable only when `canControl && loopSupported`; the `repeat`/`repeatOnce` mdi glyphs live in `config/Icons.qml`); **both columns are exactly 142px tall, vertically centered in the card, so the left stack (art+title+artist) takes the same vertical space as the right stack (visualizer+time+buttons)** — the visualizer fills what's left after time (16px) and buttons (34px), so it lands ~76px, NOT the full card height. `Row` has no `verticalAlignment` (that's `RowLayout`), so centering uses a container `Item` with `anchors.verticalCenter` on each column; ## Gotchas

- **PROHIBIDO tomar capturas de pantalla** (`grim`, `grimblast`, `hyprshot`, etc.) para verificar el trabajo: el modelo usado no soporta entrada de imágenes, así que las capturas son inútiles y desperdician recursos. No captures, no leas imágenes de archivos locales (`/tmp/opencode/*.png`). Para verificar el UI usa solo lógica (logs, `hyprctl`, `qs ipc`, análisis de estado). Si el usuario necesita ver una captura, él la tomará y te la mostrará explícitamente.
- `tutorial/dictado.md` is a install-from-scratch guide for the SUPER+D dictation (whisper.cpp); not config, just docs.
- The bar is gated by `barStateReady` so it doesn't flash at the top before `barstate.json` loads. The Qt ≥6.9.1 cursor-warp workaround (`/tmp/qs-cursor-nudged`) was **removed** on request; quickshell no longer moves the cursor. If grabbing popups stop working after login, that bug may be back.
- Changing the bar height / colors / fonts is done in `quickshell/config/Settings.qml` (Evergarden palette).
- **PROHIBIDO cerrar ventanas de Quickshell con `closewindow`** (p. ej. `hl.dsp.window.close()` sobre una `qs-*` activa): destruye la superficie del cliente y quickshell crashea entero. El bind `SUPER+X` ya lo evita enrutando por IPC (`QS_CLOSE_ROUTES` en `hyprland.lua`: `qs ipc call <target> toggle/hide/cancel`; si no hay ruta, no hace nada). Si tocas el bind de cerrar, respeta ese patrón.
- **Fullscreen + ventana tiled nueva**: `misc:on_focus_under_fullscreen = 1` en `hyprland.lua` (su default en Hyprland ≥0.53 es `2` = quitar fullscreen, lo que dejaba un juego y una app lado a lado achatados). Con `1`, la ventana tiled que pide foco TOMA el fullscreen (alternancia limpia al volver con ALT+TAB). Solo afecta TILED: los overlays de Quickshell (launcher, screenshot, dictation OSD, quickaccess, clipboard) son flotantes y quedan exentos, por eso las capturas siguen funcionando sobre un juego fullscreen. No hay equivalente por-clase (es global).
- El QuickAccess se pinta por encima de un juego a pantalla completa cubriente (Dota 2) **sin hacer NADA especial en Hyprland ≥ 0.56**: `allowedOverFullscreen` (campo interno `m_allowedOverFullscreen`) es `true` por defecto en toda ventana (`src/desktop/view/Window.hpp`) y las flotantes nuevas lo heredan ("all new floating windows are allowed over existing FS windows"). OJO — `allowed_over_fullscreen` **NO es una prop válida de `hl.dsp.window.set_prop`** (daría `Runtime error in lua: =[C]:-1:Invalid prop name` en cada apertura: `checkResult`→`reportError`→`addError`, sin lanzar error Lua, por eso un `pcall` NO lo captura) **ni un campo válido de `hl.window_rule`** (daría `unknown field`). Como ventana flotante del tamaño del monitor quedaba DETRÁS del juego (no manipulable) SOLO si se le aplicaba `fullscreen` (Hyprland fija `m_allowedOverFullscreen = false` al hacerlo y la ventana **retiene ese estado entre hide/show**, así que nunca se le debe aplicar `fullscreen`, aunque luego se quite). La ventana solo se pinta por encima si tiene el foco (al abrirla la toma gracias a `stay_focused`/`no_initial_focus false`). El bind `SUPER+B` se define en `hypr/modules/quickshell/quickaccess.lua` (no en `hyprland.lua`) y solo hace el toggle por IPC — si añadieras otro bind SUPER+B, el toggle se haría dos veces.
